about=Builds mHM model setups: domain delineation and outlet snapping, DEM
 derivatives, soil, land cover, geology and LAI, meteorological forcing on
 aligned model grids, namelist editing with nml-tools, and running mHM.
 Python dependencies are listed in requirements.txt in the plugin folder. On
 first start the plugin offers to install missing ones with pip --user into the
 Python that QGIS uses. If that fails, install them manually with that Python:
 in the plugin folder run python -m pip install --user -r requirements.txt
 (on Windows from the OSGeo4W Shell; on Linux or macOS with QGIS's Python).
 Without QGIS Desktop, install the standalone app with pip install mhm-qgis and
 run mhm-qgis; its first launch installs a private QGIS runtime.
 mHM 5.13.4 comes from the mhm Python package; for mHM v6 select a compatible
 executable in the Configuration tab.
