about=Builds mHM model setups: domain delineation and outlet snapping, DEM derivatives, soil, land cover, geology and LAI, meteorological forcing on aligned model grids, namelist editing with nml-tools, multi-domain runs, and running mHM as named cases. The Outputs tab analyses runs: water balance, hydrographs, signatures, events, validation, comparison, extremes and droughts.
 Python dependencies are listed in requirements.txt in the plugin folder. On first start the plugin offers to install missing ones with pip --user into the Python that QGIS uses. If that fails, install them manually with that Python: in the plugin folder run python -m pip install --user -r requirements.txt (on Windows from the OSGeo4W Shell; on Linux or macOS with QGIS's Python).
 mHM 5.13 comes from the mhm Python package (the mhm command); for mHM v6, select a compatible executable in the Configuration tab.
